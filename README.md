## ✨ Características Principales

- 🔍 **Buscador Inteligente Instantáneo:** Filtra por función, tecla o descripción (compatible con `/` y `Ctrl+K`).
- 📋 **Copia con un Clic:** Toca cualquier combinación de teclas para copiarla al portapapeles.
- 🪟 / 🍎 **Filtro por Sistema Operativo:** Alterna entre atajos para Windows, Mac o ambos.
- ⭐ **Sistema de Favoritos:** Guarda tus atajos más usados localmente (`localStorage`).
- 🕘 **Historial Reciente:** Mantén a la mano los últimos atajos copiados.
- 🌙 **Modo Oscuro / Claro:** Adaptable a tus preferencias visuales.
- 🖨️ **Optimizado para Impresión:** Al presionar `Ctrl + P` genera una vista limpia sin botones ni herramientas.
- 📱 **Diseño 100% Responsivo:** Compatible con móviles, tablets y escritorio.
